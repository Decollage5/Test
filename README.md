# Tetris

Ein klassisches Tetris-Spiel im Browser, umgesetzt mit HTML5 Canvas und Vanilla JavaScript (keine Abhängigkeiten).

## Spielen

Öffne einfach `index.html` in einem Browser.

## Steuerung

| Taste         | Aktion              |
| ------------- | ------------------- |
| ← / →         | Stein bewegen        |
| ↑             | Stein drehen         |
| ↓             | Weiches Fallen (Soft Drop) |
| Leertaste     | Hartes Fallen (Hard Drop) |
| P             | Pause                |

## Funktionen

- 7 klassische Tetromino-Formen (I, J, L, O, S, T, Z)
- Rotation mit einfachem Wall-Kick
- Vorschau des nächsten Steins
- Punkte-, Level- und Reihenzähler
- Steigende Geschwindigkeit pro Level
- Game-Over- und Pause-Overlay
